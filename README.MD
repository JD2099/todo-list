Overview

This project is a simple To-Do List application made with JavaScript. Users can add, complete, and delete tasks.

The purpose of this project is to practice JavaScript functions, arrays, DOM manipulation, recursion, and error handling.

Software Demo Video

Development Environment

I used Visual Studio Code and a web browser to develop and test the application.

The project uses HTML, CSS, JavaScript, and the SweetAlert2 library.
